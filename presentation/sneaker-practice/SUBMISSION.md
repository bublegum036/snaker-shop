## Проверить реальный состав

Для Git,если проект ведётся в репозитории:

```sh
git check-ignore .env
git ls-files -- .env
git status --short
```

Первое показывает правило,второе — отслеживается ли.env,третье — что менялось. Эти команды не являются аудитом истории или полноценным сканированием секретов. Если.env уже был опубликован,простого добавления.gitignore недостаточно;разберите конкретную ситуацию отдельно.

Для архива откройте список содержимого перед передачей. Исключите.env,.venv/,__pycache__/,локальные дампы и записи экрана с токенами. `.gitignore` не управляет произвольным ZIP. Не отправляйте секреты для удобства запуска:проверяющий создаст свои по примеру.
