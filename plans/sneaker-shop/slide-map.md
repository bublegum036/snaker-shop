# Карта слайдов по бэкенду магазина кроссовок

Реализованная карта содержания на 192 слайда. Сначала объясняем технологии на одном магазине, затем выполняем задание M0–M6 с помощью нейросети. [Этапы работы, правила подачи и учебные решения](README.md) описаны отдельно.

Все 192 слайда реализованы в [HTML](../../presentation/sneaker-backend.html) и [PDF](../../presentation/sneaker-backend-chapters-1-18.pdf). Главы 17–18 ожидают проверки автора: [отдельный PDF](../../presentation/sneaker-backend-chapters-17-18.pdf), [практика M6 и финал](../../presentation/sneaker-practice/M6-FINAL.md). Код, чистый запуск и API проверены; личные CONCEPT и демонстрацию ученик готовит по шаблону и инструкции.
